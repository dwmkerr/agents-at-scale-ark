# Ark Tasks

This guide describes how to complete tasks in Ark. Read this guide - we follow a simple approach where each step of the task is broken down - understanding intent, design, verification, iteration, development and testing and then final review. Many team members may provide input at each step.

You can start by copying the template at `./tasks/00-template`.

## How we work

To complete tasks in Ark, we must understand intent and objectives. We must work with the user to understand their goals. We wait for the user's review and approval before proceeding to the next step.

Once this has been clarified, we must design the architecture that would enable the objectives. We wait for the user's review and approval before proceeding to the next step.

Next we build a verifyable prototype - this means a prototype that we can interact with programatically, via APIs or interfaces (depending on the design) and use to veify design decisions. This allows us to then iterate on the architecture and objectives. We wait for the user's review and approval before proceeding to the next step.
